# AGENTS.md — профиль проекта HldsMonitoring

Профиль пайплайна фич (`feature-delivery`). Все проектные привязки берутся отсюда.

## Что это
Native Metamod-плагин для ReHLDS (Half-Life Dedicated Server), собирающий телеметрию для диагностики отключений игроков. Плюс офлайн-инструменты анализа.

## Привязки пайплайна
- **Язык документации:** русский (идентификаторы/код — английский).
- **Design doc:** `docs/design.md` (индекс — этот файл).
- **Plan:** `docs/plan.md`.
- **Journal / decision log:** `docs/journal.md` (индекс — этот файл).
- **Открытые вопросы владельцу:** раздел «Открытые вопросы» в `docs/design.md` §16.
- **Design-review агент:** `oracle` (независимый ревьюер дизайна).
- **Plan-review агент:** `momus` (независимый ревьюер плана).
- **Скиллы ролей:** design → `software-architect`; code → `developer`; tests/DoD → `qa-engineer`; сборка/деплой → `devops-engineer`; безопасность → `security-engineer`.

## Команды верификации
- `make` — сборка плагина (32-бит, `-m32`).
- `make test` — хостовые unit-тесты (C++) + тесты инструментов анализа (Python).
- `make clean` — очистка.
- Линтер: компилятор с `-Wall -Wextra` (отдельного линтера нет).

## Политика коммитов
- Коммит только по **явной** просьбе владельца, один связный коммит на стадию (код + тесты + доки + запись журнала). Без авто-коммитов.

## Ограничения
- Целиком на Linux в v1; Windows — отдельная фаза.
- HLDS 32-бит. `cmake`/`ninja` нет — сборка Makefile.
- Плагин **пассивный** в v1 (никогда не дропает пакеты).
- Интеграционный запуск требует реального ReHLDS-сервера — вне CI; покрывается хостовыми unit-тестами ядра.

## Артефакты стадии (эталон)
`docs/design.md` → `docs/plan.md` → код в `src/`, `tools/` → `docs/journal.md`.
